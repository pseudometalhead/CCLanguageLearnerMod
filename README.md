# Language Learner (Claude Code mod)

A Duolingo-style language learning pane for Claude Code. Type `/learn` to open it.

- Courses: Spanish, French, German, Italian, Japanese (romaji), 3 lessons each
- Multiple-choice quizzes in both directions (target→English, English→target)
- XP, 5 hearts per lesson, daily streaks; progress saved across sessions via `$.store`

Load with `claude --plugin-dir /path/to/this/repo`.
